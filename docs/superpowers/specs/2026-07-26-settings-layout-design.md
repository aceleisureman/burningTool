# 设置页面分组布局设计

## 目标

在不修改配置字段、状态来源和事件处理逻辑的前提下，重新组织工具链设置页，降低长页面阅读压力，让用户先看到环境状态，再按任务完成配置。

## 页面结构

1. 顶部操作栏：保留恢复默认、取消、保存，随页面固定。
2. 环境概览：集中展示操作系统、架构、Keil 支持和默认下载包，并显示工具链整体就绪数量。
3. 编译与烧录：集中编译方式、烧录方式、Keil 条件项、芯片识别、复位连接和 ELF 文件名。
4. 默认工具链：仅在默认工具链模式显示；工具状态使用紧凑双列卡片，保留详情、进度、下载和强制重下载。
5. 路径与系统集成：集中工具链保存目录、CubeMX、下载镜像和系统 PATH；自定义工具链路径仅在自定义模式显示。

## 交互约束

- 所有原有 `v-model`、`v-if`、点击事件和状态展示保持不变。
- 默认工具链状态项仍可点击查看详情。
- 窄窗口下双列工具状态自动降为单列。
- 使用已有主题变量，兼容当前浅色和深色主题。
